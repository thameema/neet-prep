**Question 1:**  A newly discovered marine invertebrate exhibits radial symmetry, a coelom, and a complete digestive system.  Which phylum is it MOST likely to belong to?

A) Cnidaria
B) Platyhelminthes
C) Echinodermata
D) Annelida

**Correct Answer: C**

**Question 2:**  Which of the following represents a CORRECT comparison between the respiratory systems of a prawn and a cockroach?

A) Both possess gills for aquatic respiration.
B) Both possess tracheae for terrestrial respiration.
C) Prawn uses gills, while cockroach uses tracheae.
D) Prawn uses lungs, while cockroach uses spiracles.

**Correct Answer: C**
**NCERT Reference:** Chapter 4, Respiratory system descriptions for Arthropoda

**Question 3:**  A parasitic organism lacks a coelom, shows bilateral symmetry, and has a well-developed organ system. To which phylum does it MOST likely belong?

A) Porifera
B) Ctenophora
C) Platyhelminthes
D) Nematoda

**Correct Answer: C**  (Though Nematoda is also acoelomate, the question emphasizes a *well-developed* organ system, which is more characteristic of Platyhelminthes amongst the options)
**NCERT Reference:** Chapter 4, Phylum descriptions focusing on body cavity and organ system development.

**Question 4:**  Considering the characteristics of Hemichordata, which statement BEST explains its ambiguous taxonomic position?

A) It possesses notochord only in larval stage.
B) It exhibits both chordate and non-chordate features.
C) It lacks a post-anal tail.
D)  It shows radial symmetry.

**Correct Answer: B**
**NCERT Reference:** Chapter 4, Hemichordata description highlighting its intermediate characteristics.

**Question 5:**  An organism shows metamerism, a closed circulatory system, and nephridia for excretion.  Which phylum does it belong to?

A) Mollusca
B) Arthropoda
C) Annelida
D) Echinodermata

**Correct Answer: C**
**NCERT Reference:** Chapter 4, Annelida description


**Question 6:**  Which of the following is NOT a characteristic shared by all chordates at some point in their life cycle?

A) Notochord
B) Dorsal hollow nerve cord
C) Pharyngeal slits
D) Post-anal tail

**Correct Answer: A** (Some chordates lose their notochord during development)
**NCERT Reference:** Chapter 4, Chordata characteristics

**Question 7:**  Which phylum exhibits exclusively parasitic forms?

A) Cnidaria
B) Platyhelminthes
C) Annelida
D) Arthropoda

**Correct Answer: B** (While some members of other phyla are parasitic, Platyhelminthes are exclusively so)
**NCERT Reference:** Chapter 4, Platyhelminthes description

**Question 8:**  A vertebrate possesses cartilaginous endoskeleton, possesses paired fins, and lacks scales.  Which class does it belong to?

A) Chondrichthyes
B) Osteichthyes
C) Amphibia
D) Reptilia

**Correct Answer: A**
**NCERT Reference:** Chapter 4, Chondrichthyes description
